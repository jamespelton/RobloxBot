## #📋-rules

```
**Crystal Siege Server Rules** 🔮

1. **Be kind.** No bullying, no harassment, no slurs. Period.
2. **Keep it PG.** Our audience is 9-13. No swearing, no inappropriate content, no NSFW anywhere.
3. **No DM advertising.** Don't slide into people's DMs to promote other games or servers.
4. **No invite links** to other Discord servers (unless approved by mods).
5. **No spam** — including emoji spam, caps lock spam, copy-paste spam.
6. **No exploits or hacks.** Don't share, ask about, or promote game exploits.
7. **Use channels for their purpose.** Bug reports in #🐛-bug-reports, not in #💬-general.
8. **One language: English.** Other languages welcome in DMs, but server channels keep it English so mods can moderate.

**Breaking these rules = warning → mute → kick → ban.**

Questions? Ask a 🛡️ Mod.

---

🔔 React below to opt in to **Update Pings** — get notified every Friday when a new update + code drops.
🎯 React with 🎯 to opt in to **Looking For Group** pings.
```
